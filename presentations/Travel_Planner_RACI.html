05

Responsible and accountable

The specialist performs the work; the Manager owns the combined result

For hotel research, the Hotel Agent is responsible. The Manager is accountable within this teaching model because it consumes the report and assembles the plan.

For draft review, the Critic is responsible. The Manager owns the response to that review. Naming an AI agent accountable does not transfer real-world liability away from people.

A real product still needs a human owner and explicit approval rules.

build_raci validates the selected team

Unknown names fail; repeated names produce one row

Notebook codePython
def build_raci(workers):
    unknown = set(workers) - set(WORKER_TASKS)
    if unknown:
        raise ValueError(f"Unknown workers: {sorted(unknown)}")
    selected = list(dict.fromkeys(workers))
    if not selected:
        raise ValueError("Select at least one travel specialist.")
    rows = [RACIEntry("Understand request and select team", "Manager", "Manager")]

Empty selections and unknown workers raise ValueError. dict.fromkeys preserves selection order while removing duplicates. The original Manager falls back to all workers if its response contains no valid names.

13

print_raci displays the matrix

The table is readable during a live class

Notebook codePython
def print_raci(entries):
    table = Table(title="RACI — SELECTED TRAVEL TEAM", show_lines=True)
    for column in ("Task", "R: Responsible", "A: Accountable", "C: Consulted", "I: Informed"):
        table.add_column(column)
    for entry in entries:
        table.add_row(entry.task, entry.responsible, entry.accountable,
                      entry.consulted or "—", entry.informed)
    console.print(table)

Rich formats the five columns. An empty consulted field displays a dash. This function does not call agents or send notifications.

16

Why the execution log needs a reducer

Multiple workers can write in one graph step

Notebook codePython
import operator
from typing import Annotated

execution_log: Annotated[list[dict[str, str]], operator.add]

The append reducer combines worker records instead of replacing the shared list. Separate flight_report, hotel_report and activity_report fields avoid report conflicts.

The displayed list is a graph trace. Its parallel entries do not establish precise wall-clock completion order.

17

with_raci is a plain function

Pass the task name and its completed result

Notebook codePython
def with_raci(task_name, task_result):
    """Add the task's ownership record to its normal result."""
    roles = NODE_ROLES[task_name]

    if task_name == "manager":
        task_result["raci_entries"] = build_raci(task_result["chosen_workers"])
        print_raci(task_result["raci_entries"])

    task_result["execution_log"] = [{
        "step": task_name,
        "responsible": roles["responsible"],
        "accountable": roles["accountable"],
        "status": "completed",
    }]
    return task_result

The helper reads the named responsible and accountable fields, adds a completed record and returns the same result. It does not receive or return a function. The Manager also builds the selected-team matrix.

18

Each node adds its own record

The task runs first, then the helper receives its result

Notebook codePython
def flight_node(state):
    """The flight agent works on its part."""
    # NEWLY ADDED: run only workers selected by the Manager.
    if "flight_agent" not in state["chosen_workers"]:
        raise ValueError("flight_agent was not selected for this trip.")
    report = ask(flight_agent, f"Find flights for this trip.\n\n{state['requirements']}")
    # NEWLY ADDED: add ownership details to this completed task.
    return with_raci("flight_agent", {"flight_report": report})

The flight node checks selection before doing work. After ask returns the report, with_raci attaches ownership details. If the task raises an error, this return never executes and no completed record is added.

23

Validation and classroom exercise

The graph runs with deterministic model fixtures in local tests

  • All seven non-empty worker subsets execute through real LangGraph.
  • Synthesis runs once after the selected workers.
  • Matrix rows and completion records match the selected team.
  • Unknown workers, empty requests and negated critic phrases have regression checks.

Live Colab with real OpenAI calls remains unverified. Fixtures are static travel data. API access and billing are required for live model runs.

Class exercise: compare a full trip with a flights-only request, then identify which rows and log entries disappear.
