The companion projects

mood-app is the worked example for session two: a notes app with a chatbot that calls seventeen real tools. Every answer has an eye button that opens the full JSON of what was sent to the LLM, which tools ran, and what came back. simple_agent_chatbot is the smaller one from session three — the agent loop with nothing else around it.

Both need a Python backend, so they cannot run on this page. They live in the same repository as these decks — clone it and follow the SETUP.md inside each project folder.
