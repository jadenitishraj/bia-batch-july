# Teaching purpose

This repository is for teaching. Write clean, simple code that students can understand.

- Prioritize readability and simplicity over efficiency and optimization.
- Use clear names and straightforward, step-by-step code.
- Avoid clever tricks, complex code, and unnecessary abstractions.
- Explain unfamiliar ideas in plain English. Keep explanations and comments short.
- When simplifying code, preserve its intended behavior and essential safety checks.
- Implement only the requested lesson or change.
- After completing and checking requested work, open a focused pull request and let the user know. Do not merge or deploy unless asked.
